This module extends the invoice report to show the expiration date for
each tracked lot in the invoiced lots summary table.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Usage
=====

To use this module, you need to:

1. Enable the **Display Lots & Serial Numbers on Invoices** setting.
2. Create or use a product tracked by lots with expiration dates
   enabled.
3. Deliver and invoice a lot-tracked product.
4. Print the invoice.

The invoiced lots summary table will include an **Expiration Date**
column.
